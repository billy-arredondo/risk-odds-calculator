# Risk Odds Calculator

Angular application for the Risk Odds Calculator project. It currently displays the Angular starter
page; probability calculations have not yet been implemented.

## Quick start

With Node.js and npm installed, run the following from the repository root:

```bash
npm ci
npm start
```

Open [http://localhost:4200/](http://localhost:4200/).
